# Проверка единого запуска — 2026-10-05

Подключены JS Secrets, IDOR, Subdomain Monitor и Smuggling. Старые standalone
копии этих инструментов не нужны: используй версии внутри этого архива.

Проверка: `python3 -m unittest -v test_integration_all` — **10/10 успешно**.

1. Флаги launcher, отключение стадий, SSRF/OAST и синтаксис Python 3.10.
2. Сохранение JS URL без параметров и фильтрация scope/портов.
3. Весь serial-конвейер через subprocess с проверкой argv настоящими CLI-парсерами.
4. Parallel для GET/POST; остальные стадии не пересекаются с ними.
5. Продолжение IDOR/Smuggling после ошибки JS-процесса.
6. Offline dry-run с готовым Recon не запускает дочерние сканеры.
7. Отсечение IDOR URL вне scope и поведение без IDOR-конфигурации.
8. Точный scope монитора и совместимый summary Smuggling с правами 0600.
9. Таймаут и остановка дочернего процесса.
10. Настоящий `start.py` → exec → `pipeline_manager.py` в offline dry-run.

Сканеры в интеграционных тестах заменялись локальными исполнителями, которые
вызывают настоящие парсеры аргументов. Внешние сайты не сканировались. Это проверка
совместимости и orchestration, а не подтверждение обнаружения уязвимостей на
реальных целях. Полный старый набор тестов повторно не запускался.
